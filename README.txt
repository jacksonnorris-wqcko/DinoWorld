Dino World v0.0.12 — changed files only

This release targets the issues visible in the iPhone screenshot: dinosaur cutouts are smaller and spread across the meadow, and activity icons have strict fixed dimensions and containment so they cannot fill or overflow the hotbar tiles. CSS/script URLs are versioned to help avoid stale Safari assets.

Upload these five files to the ROOT of your existing GitHub repository, replacing matching files:
- index.html
- styles.css
- app.js
- sw.js
- version.json

Do not upload the ZIP itself. Extract it first. Wait for GitHub Pages to deploy, then close and reopen Dino World and check v0.0.12.
