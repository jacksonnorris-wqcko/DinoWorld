Dino World v0.0.24 patch

Replace these files in the existing Dino World repository: index.html, app.js, sw.js, version.json. Keep your existing styles.css, artwork.js, manifest.json, icon.svg and apple-touch-icon.png.

This release adds continuous gentle idle bob/sway to the large selected dinosaur, character-specific tap reactions, reduced-motion support, and version/cache updates. It intentionally retains the current character artwork and layout.

Validation performed: JavaScript syntax check and package integrity checks. This package has not been run on a physical iPhone in this environment. Blinking and independently articulated tail animation are not included in this patch; those need proper separate character layers/frames rather than pretending a whole-image wiggle is a moving tail.
